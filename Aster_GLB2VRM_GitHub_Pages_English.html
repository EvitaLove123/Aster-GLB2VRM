Model Rotation

Rotation is applied to the model root and included in the exported file. A 180° rotation around the Y axis is common, but check the model’s forward-facing direction in your target application.

Model Scale

Scale is applied to the model root and included in the exported VRM. Use uniform scaling to avoid distorting the character’s proportions.

Remove Meshes

Deleting a mesh removes it from both the preview and the exported file. This cannot be undone; re-import the original model to restore it.

Auto T-Pose is intended only for models in an A-pose. If the model uses another custom pose, adjust it manually or restore the original pose. This is not a general-purpose pose converter.

3. Auto Bone Mapping

Mapping supports English/MMD names, detects R/L side markers even inside names, and normalizes full-width digits. Large numeric suffixes (_3…_12) are not automatically selected as finger segments. Standard unsuffixed names are preferred, followed by _1 when no standard name exists. Always review suggested bones.
